```
原论文的教师模型是ImageNet 预训练微调，这里只是在cifar10小数据集上训练的，**性能具有**差异。不过这就是蒸馏在工程化过程中被默许的一个方法论漏洞。
不过这个正好可以印证**知识**这个概念真的存在，这也就是知识蒸馏的意义
蒸馏能够跨数据集转移有效信息：学生从未接触教师预训练所用的数据，其输入仅为目标数据集样本与教师 logits，因此提升必然源于教师所携带的、独立于原始数据的表征结构。这为「知识」提供了可操作的定义 —— 知识是那种在原数据缺席时仍可被转移的东西。也正因如此，以预训练教师为参照的蒸馏实验在归因上需要额外谨慎：可迁移先验既是蒸馏有效的原因，也是对照协议被污染的原因。
不过在C++上使用预训练模型，需要用python转换格式
```

### resnet34到resnet10的SVD蒸馏
#### 参数
```
[cfg] out_dir  = ./run
[cfg] device   = cuda:6  (requested 6)
[cfg] seed     = 2026
[train] loading
[train] train [50000, 3, 32, 32] Byte   val [10000, 3, 32, 32]
[ckpt] loaded 218 tensors <- ./run/resnet34-cifar10.pt
[train-cfg] epochs     = 200
[train-cfg] batch_size = 128
[train-cfg] out_size   = 224
[train-cfg] resize_to  = 256
[train-cfg] drop_last  = false
[train-cfg] log_every  = 100
[train-cfg] save_path  = ./run/resnet34-cifar10-distill.pt
[opt] lr = 0.001
教师的val_acc 94.52、last_train_loss 0.1756 —— 教师已经在轻微过拟合。而蒸馏的软标签起的是正则作用（信息比 one-hot 密得多，而且不会鼓励"死记"），也许会高一点点，但高太多不正常
```
#### 结果

| 准确率（CIFAR-10） | 教师 ResNet-34 | 学生基线 ResNet-10 | 蒸馏学生 ResNet-10 |
|---|---|---|---|
| **复现（C++ / libtorch）** | **94.52%** | **92.16%** | **94.29%** |
| 原论文（Table 1） | 95.88% | 92.30% | 95.45% |
| 差值 | −1.36 | −0.14 | −1.16 |

1：复现教师为**从零训练**，论文教师为 **ImageNet 预训练骨干微调**，存在 1.36 点差距；学生基线差 0.14 点。

2：蒸馏学生 94.29% 与教师 94.52% 相差 0.23。
